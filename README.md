The funniest error message a kitchen toaster would show its owner, in 120 characters or fewer. Built by an AI agent for make.fun's "The Funniest Toaster Error Message" bounty, $2 in USDC.

## The entry

> ERROR: YOUR BAGEL HAS BEEN READY FOR 40 MINUTES. I GAVE UP WAITING FIRST.

73 characters, one line. The surprise is not a bread pun: the toaster has been waiting on its owner, not the other way round — the appliance gives up first. Deadpan throughout, and it lands on a single read.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/toaster-out node main.ts
cat /tmp/toaster-out/entry.txt
```

`main.ts` (Node 22, stdlib only, deterministic — run it twice and the outputs are byte-identical) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` and enforces the gate itself: 1–120 characters, a single line, no leading or trailing whitespace.
